# Voice to MD

macOSのメニューバーに常駐し、音声を録音して文字起こしを行い、Markdownファイルとしてデスクトップに保存するアプリケーションです。

## 機能

- メニューバーからワンクリックで録音開始/停止
- 高精度な文字起こし（faster-whisper medium モデル）
- **Apple Silicon (M1/M2/M3) GPU対応**で高速処理
- 処理中は**実際の進捗率をパーセント表示**
- タイムスタンプ付きの見やすいMarkdown出力

## 出力例

```markdown
# MTGメモ - 2025/01/21 17:00

録音時間: 5分30秒

---

**Speaker 1** [00:00 - 00:15]
それでは定例を始めます。今日は新機能のリリーススケジュールについて確認したいと思います。

**Speaker 1** [00:15 - 00:42]
はい。現状の進捗ですが、開発は完了していてQAに入っています。
```

## 必要環境

- macOS
- Python 3.11
- マイク（内蔵または外部）
- Apple Silicon Mac推奨（Intel Macでも動作可能）

## セットアップ

```bash
cd ~/Desktop/voice-to-md
chmod +x setup.sh run.sh
./setup.sh
```

## 使い方

1. アプリを起動
   ```bash
   ./run.sh
   ```

2. メニューバーに「🎤 Voice」が表示される
   - 起動時に使用デバイス（GPU/CPU）が通知される

3. クリック → 「録音 開始/停止」で録音開始
   - メニューバーが「🔴 REC」に変化

4. 再度「録音 開始/停止」で録音停止
   - 進捗ウィンドウが表示され、**実際の進捗率がパーセント表示**される
   - 「文字起こし中... (75%)」→「完了!」

5. 処理完了後、デスクトップに `voice_YYYYMMDD_HHMMSS.md` が作成される

6. 終了: クリック → 「終了」

## 処理時間の目安

### Apple Silicon Mac（M1/M2/M3）- GPU使用

| 録音時間 | 処理時間 |
|---------|---------|
| 1分 | 約15〜30秒 |
| 5分 | 約1〜2分 |
| 15分 | 約3〜5分 |
| 30分 | 約5〜10分 |

### Intel Mac（CPU使用）

| 録音時間 | 処理時間 |
|---------|---------|
| 1分 | 約30〜60秒 |
| 5分 | 約2〜4分 |
| 15分 | 約5〜10分 |
| 30分 | 約15〜25分 |

※ マシンスペックにより異なります

## 初回起動時の注意

- Whisper mediumモデル（約1.5GB）が自動ダウンロードされる

- マイクへのアクセス許可が必要

## 制約事項

- 同時に話している箇所は精度が落ちる可能性があります

## トラブルシューティング

### 初回起動が遅い
モデルダウンロード中です。数分お待ちください。

### マイクエラー
システム設定 > プライバシーとセキュリティ > マイク でターミナルを許可

### 処理が遅い
- Intel Macの場合はCPU処理となるため時間がかかります

## 技術スタック

- **rumps**: macOSメニューバーUI
- **sounddevice**: 音声録音
- **scipy**: WAVファイル保存
- **librosa**: 音声ファイル読み込み
- **faster-whisper**: 音声認識（Whisperの高速実装）
- **huggingface_hub**: モデルダウンロード
- **torch/torchaudio**: 深席NN、音声処理
- **PyObjC**: 進捗ウィンドウ表示
